## 🎯 Présentation
Site vitrine complet pour lassociation de danse Arabesque. Inclut un panneau dadministration, une présentation des professeurs, les horaires, une galerie photos, des témoignages et un formulaire de contact.

---

## ✨ Fonctionnalités
- ✅ Panneau dadministration
- ✅ Présentation des professeurs et horaires
- ✅ Galerie photos
- ✅ Témoignages et FAQ
- ✅ Formulaire de contact

## 🚀 Installation
```bash
git clone https://github.com/MattiaPARRINELLO/Projet-Site-Vitrine-Danse.git
cd Projet-Site-Vitrine-Danse
npm install
npm start
```
